# 电商评论情感分析与模型轻量化（公开京东评论数据集）

以「差评优先发现」为核心目标的评论情感二分类实验项目：基于 5 万条公开京东评论数据集，完成 TF-IDF+随机森林 / fastText / BERT 全参数微调三模型同口径横向对比，并在 CPU 部署硬约束下实践模型轻量化三件套（INT8 动态量化 / 知识蒸馏 / 结构化剪枝），Flask 推理服务 + Streamlit 界面全链交付。

## 实测结果（完整 4988 条测试集，同一数据底座，可复现）

| 模型 | 准确率 |
|---|---|
| TF-IDF + 随机森林（基线） | 83.1% |
| fastText（词 + 字符 n-gram 子词） | 87.0% |
| BERT 特征抽取（误用 no_grad 的反面对照） | 84.75% |
| **BERT 全参数微调** | **90.52%** |

## 关键实验点

- **no_grad 踩坑与修复**：训练脚本 forward 误用 `torch.no_grad()` 冻住主干，BERT 退化成「特征抽取 + 训分类头」（84.75%，打不过 fastText）；去掉 no_grad 让梯度回传主干后 90.52%——完整的「微调 vs 特征抽取」对照。
- **数据工程**：5 万条评论清洗（去重、去无意义短评）、正负均衡、9:1 划分（训练约 4.5 万 / 测试 4988 条）；处理 NaN 标签列错位等边界问题，保证三模型同一数据底座、结果可直接对比。
- **模型轻量化（CPU 部署硬约束）**：
  - INT8 动态量化：只对 Linear 层，无需校准集；
  - 知识蒸馏：BERT 教师 → BiLSTM 学生（软标签 + 温度）；
  - 结构化剪枝：Q/K/V 权重 L1 剪枝 30%，精度不降反微升。
